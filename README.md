# Nhật ký xây nhà

Trang kể chuyện cho người lần đầu xây nhà, xuất bản tại https://nhatkyxaynha.com qua GitHub Pages.

- `index.html`: toàn bộ trang (một tệp, không cần build).
- `CNAME`: tên miền riêng cho GitHub Pages. Không xoá tệp này.
- `.nojekyll`: báo GitHub Pages phục vụ tệp nguyên bản, không chạy Jekyll.

Sửa nội dung: chỉnh `index.html`, commit lên nhánh `main`, trang tự cập nhật sau 1–2 phút.
