# Nhật ký xây nhà

Trang kể chuyện cho người lần đầu xây nhà, xuất bản tại https://nhatkyxaynha.vn qua GitHub Pages. Tên miền nhatkyxaynha.com chuyển hướng về nhatkyxaynha.vn.

- `index.html`: toàn bộ trang (một tệp, không cần build).
- `CNAME`: tên miền riêng cho GitHub Pages (`nhatkyxaynha.vn`). Không xoá tệp này.
- `.nojekyll`: báo GitHub Pages phục vụ tệp nguyên bản, không chạy Jekyll.

Sửa nội dung: chỉnh `index.html`, commit lên nhánh `main`, trang tự cập nhật sau 1–2 phút.
